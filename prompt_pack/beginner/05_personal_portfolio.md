# 🎨 Personal Portfolio Site

**Difficulty:** Beginner

## Overview
Build a stunning personal portfolio website that showcases your projects, skills, and personality. This isn't a generic template — it's a site that reflects who you are and what you've built.

## Objectives
- A multi-page portfolio site with a homepage, projects page, and about page
- Project showcase with descriptions, tech stacks, and links
- Skills section with visual proficiency indicators
- Contact form or links to social profiles
- Responsive design that looks great on all devices
- Fast loading and clean SEO fundamentals

## Features
- [ ] Homepage with a hero section and brief intro
- [ ] Projects page showing 3-6 projects with screenshots, descriptions, and links
- [ ] About page with skills, background, and personality
- [ ] Contact section with email link or form
- [ ] Responsive design (mobile-first)
- [ ] Fast loading (minimal dependencies, optimised assets)
- [ ] Clean URL structure and basic SEO (meta tags, semantic HTML)
- [ ] Dark/light theme or a distinctive visual identity

## Technical Suggestions
- **HTML/CSS/JS** — vanilla for maximum control and minimal overhead
- **Tailwind CSS** — for rapid, consistent styling
- **Alpine.js** — for lightweight interactivity without React overhead
- **Static hosting** — GitHub Pages, Netlify, or Vercel (free)
- **Favicon and meta tags** — basic SEO setup

## Stretch Goals
- Add a blog section with Markdown-based articles
- Implement a project filter/tag system
- Add animations and micro-interactions (scroll reveals, hover effects)
- Create a custom 404 page
- Add a sitemap.xml and robots.txt for SEO
- Implement a dark mode with system preference detection

## Learning Outcomes
You'll learn how to plan a multi-page site, think about information architecture, design for user experience, and deploy a production website. This project teaches the full lifecycle of a web project — from planning to shipping.

## AI Instructions
1. Analyse the repository structure before writing any code.
2. Create a detailed implementation plan: page structure, design system, content strategy.
3. Ask clarifying questions if requirements are ambiguous (style preferences, projects to showcase, colour scheme).
4. Work iteratively — start with the homepage structure, then projects, then about, then polish.
5. Explain major architectural decisions (why Tailwind over custom CSS, why vanilla JS over a framework).
6. Keep milestones logically separated: structure → styling → content → interactivity → deploy.
7. Avoid unnecessary complexity — no frameworks unless they genuinely help.
8. Write clear documentation with setup and deployment instructions.
9. Add tests for any JavaScript utility functions.
10. Refactor when improvements become obvious — keep the code clean and maintainable.
11. Pause after completing each major section and summarise progress.
