# Atlas Prompt Pack

A premium collection of 15 project briefs designed to teach users how to leverage modern AI coding agents (Claude Code, Codex, Gemini CLI, OpenCode, Cline, Roo Code, Aider, etc.) to build real, production-quality projects while naturally learning software engineering best practices.

These are not tutorials. They are project briefs you can paste directly into your coding agent and get to work.

## Difficulty Levels

### Beginner
Projects for users who have never used an AI coding harness before. Teaches thinking like an engineer while producing something genuinely enjoyable to build.

Each project naturally teaches:
- Planning and task breakdown
- Reading existing code
- Asking follow-up questions
- Debugging and iterative improvement

### Intermediate
Projects requiring multiple systems working together. Introduces APIs, authentication, databases, async programming, testing, deployment, and project architecture.

### Professional
Product-grade projects someone could actually launch. Focuses on scalability, maintainability, modular architecture, logging, testing, documentation, production deployment, security, and clean APIs.

## AI Instructions (included in every prompt)

Every prompt instructs the coding agent to:

1. Analyse the repository before making changes
2. Create a detailed implementation plan
3. Ask clarifying questions when requirements are ambiguous
4. Work iteratively
5. Explain major architectural decisions
6. Keep commits or milestones logically separated
7. Avoid unnecessary complexity
8. Favour maintainable, production-quality code
9. Write clear documentation
10. Add sensible tests where appropriate
11. Refactor when improvements become obvious
12. Pause after completing major milestones and summarise progress
